# Supabase Edge Functions — Hospital Management System

This directory is prepared for Supabase Edge Functions (Deno/TypeScript runtime) to handle server-side operations that require elevated security:

## Planned Edge Functions for Part 2 & Beyond

1. **`send-urgent-alert/`**: Broadcasts STAT laboratory panic alerts and SMS notifications to attending physicians.
2. **`generate-superbill/`**: Generates digitally-signed PDF hospital invoices and tax receipts.
3. **`edi-claims-submit/`**: Pre-authorizes and submits health insurance claim payloads.
4. **`archive-audit-logs/`**: Compresses and immutably archives HIPAA access logs to long-term cold storage.
